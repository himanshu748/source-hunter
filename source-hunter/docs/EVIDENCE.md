## Reproduce the reviewed projection

From the standalone package root, after `npm ci`:

```sh
npm run review:check
```

The underlying command is:

```sh
npx tsx source-hunter/scripts/review-recorded.ts --check
```

It reads the public original batch and source-review decisions, checks the original digest, validates source and trace identities, keeps fixed observed attribution paths, enforces distinct exported excerpts of at most 25 words per source, and compares the regenerated bytes with `reviewed-batch.json`. It makes no network request, reads no credentials or private captures, and does not determine truth or provenance for arbitrary claims.

To intentionally regenerate the artifact after a reviewed decision change:

```sh
npx tsx source-hunter/scripts/review-recorded.ts
npm run review:check
```

Regeneration changes a projection, not the underlying historical provider receipt. An invalid reviewed artifact fails closed; it is not silently replaced with an older successful-looking trace. Raw receipts and full captures remain private and are not required to run the saved preview.
