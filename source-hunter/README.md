# Source Hunter

Before quoting a number, inspect its trail. Source Hunter pairs a Chrome extension with a local workbench to separate selected wording, observed citation links, supporting/refuting evidence and unanswered source questions.

Five saved investigations came from one genuine TinyResearch Deep batch and nine TinyFish Fetch checks, followed by a separate 9 November source review. An additional unseen NOAA test used one Deep run and ten Fetch checks in total: nine from the Chrome recovery and one later, explicitly authorized PDF repeat. These are distinct evidence histories.

The package remains local, unpublished, unclaimed, unsubmitted and **not ready for bounty submission**. Technical package checks and current five-case Chrome/workbench regression passed. Public judge access, required promotion, current eligibility/form checks and the owner's final prize-entry click remain open. [Evidence boundaries](docs/EVIDENCE.md).

## Run the saved preview

Use Node.js 22 or newer. Run these commands from the standalone package root, the directory containing `package.json`:

```sh
npm ci
BOUNTY_POOL_LIVE=0 npm start
```

Open [Source Hunter on localhost](http://127.0.0.1:4388/). Choose **Explore a recorded claim**, inspect its assessment, source trail, dates and gaps, then download the investigation JSON. Installation needs npm registry access; the running preview serves its scripts and fonts locally. Opening an official source link needs internet access.

Preparing a different selection does not research it. Saved lookup requires the same source URL and selected text after Unicode NFKC and whitespace normalization. It does not fuzzy-match a related claim, discard query parameters or treat arbitrary trailing slashes as equivalent. Only explicitly reviewed URL aliases are accepted.

## Use the Chrome extension

Chrome was installed with owner approval in a separate signed-out **Source Hunter Test** profile. Earlier checks passed highlights, matching lookups, dates and assessments for all five saved cases, WHO full export and a real unmatched-selection result. These passes predate the latest recovery controls and are not a final current-bundle regression.

1. Open `chrome://extensions`, enable Developer mode and choose **Load unpacked**. Select `source-hunter/extension/` from the standalone package.
2. Copy Chrome's displayed extension ID and restart the local server with that exact ID, replacing the value below:

   ```sh
   SOURCE_HUNTER_EXTENSION_ID="YOUR_EXTENSION_ID" \
   BOUNTY_POOL_LIVE=0 npm start
   ```

3. On a public source page, highlight its exact stored selection, between 10 and 1,000 characters, then open the toolbar popup.
4. Choose **Show matching saved investigation**. Inspect the run/time, scope, dates, source checks, primary/earliest statuses and full export.
5. Try a different selection. It must return no match without substitution or provider work.

The extension requests `activeTab`, `scripting` and access to `http://127.0.0.1:4388/*`. Its fixed port is 4388. The server authorizes only the configured extension origin. **Recheck local server** refreshes connection information without provider work. [Privacy notes](docs/PRIVACY.md).
